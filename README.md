# 胶囊伙伴 · 使用教程

版本：1.0.0 正式版
适用系统：Android 16+（ColorOS 16 及以上）
说明：本应用未申请接入开放平台，非 ColorOS 16+ 设备可能会出现无法上岛的情况。

胶囊伙伴是一款**纯本地离线**的轻量陪伴应用：把每天要做的事交给它，它用「今天」的时间线帮你推进，用「伙伴」的成长记录你的坚持。应用未申请任何网络权限，所有数据只保存在你的手机上。

---

## 一、安装与首次启动

1. 下载 `CapsulePal-1.0.0.apk`，点击安装；若系统提示「未知来源」，允许本次安装即可。
2. 首次打开会弹出「用户须知」，请完整阅读后点击「我已阅读并同意」。
3. 建议按引导完成授权（不授权也能用，但相关功能会受限）：

| 权限 | 用途 |
| --- | --- |
| 通知 | 提醒、实况通知 |
| 悬浮窗 | 后台保持陪伴时显示悬浮点 |
| 精确闹钟 | 提醒准点触发 |
| 电池优化白名单 / 自启动 | 避免后台被系统清理 |

> 权限随时可以在「设置 → 权限与引导」里重新检查和开启。

---

## 二、界面导航

底部五个页签依次为：**监测 / 伙伴 / 今天 / 日程 / 设置**。

| 页签 | 作用 |
| --- | --- |
| 今天 | 每天的主界面，按时间线排列今天的安排 |
| 伙伴 | 等级、成长、形象与称号 |
| 日程 | 按日历查看任务与节假日 |
| 监测 | 电池等系统状态 |
| 设置 | 提醒、权限、备份与个性化 |

---

## 三、今天：把一天排好

- **添加一件**：新增待办，可选分类、时间、是否带步骤。
- **从模板安排**：一键把常用模板填进今天。
- **下一件**：只显示当前最该做的一件事，减少选择压力。
- **完成 / 跳过 / 调整**：完成才计入成长；跳过的不会留下记录；时间不合适可随时调整。
- 顶部时间线会实时显示今天剩余安排。

小技巧：点击「今天」页顶部**伙伴气泡的任意区域**，可以直接做一次**快速备份**。

---

## 四、伙伴：成长怎么算

- 每完成一件事获得成长，等级与称号随总成长提升。
- **每天前几次完成是全额成长，之后递减**，具体次数可在「设置 → 成长节奏」里调整。
- 把「完成」改回「未完成」，对应的成长会一起回退；跳过则不算完成。
- 「形象」里可以开关扫描线、屏幕反光等外观效果，也可以更换服装。

---

## 五、主动提醒：让情境来提醒你

在「设置 → 更多提醒 → 主动提醒规则」中，可以按情境自动提醒：

- 连接 WiFi（可指定或任意）
- 插入有线耳机
- 连接蓝牙设备
- 开始充电 / 停止充电
- 通话结束
- 系统日历临近（开始前 N 分钟，全天事件自动忽略）
- 打开指定应用（需要「使用情况访问」权限）

每条规则可选：**仅显示自定义提醒**、**关联指定待办**、**自动关联最近待办**。还可以设置每日提醒上限和优先级，避免打扰过多。

---

## 六、上岛通道（实况通知）

「设置 → 上岛通道」用于把提醒显示在系统实况通知区域：

- 页面会显示当前是否「可上岛」；不可用时会给出一行原因（通常是通知权限或系统限制）。
- **上岛测试**：模拟一次 1 分钟准备 + 1 分钟进行，不计入成长与待办进度。
- **重新调度全部提醒**：改动提醒设置后如果没生效，可以点这里重排一次。

如果希望灵动岛之外再收到一条普通通知，可打开「灵动岛之外再发一条通知」。

> 本应用未申请接入开放平台，非 ColorOS 16+ 设备可能出现无法上岛的情况，属于系统限制。

---

## 七、后台保持陪伴与悬浮点

「设置 → 保活通道 → 后台保持陪伴」打开后：

- 屏幕左上角会出现一个 **1dp 的纯黑小点**，用于降低后台被系统回收的概率。
- **悬浮点隐藏**：隐藏后缩成 1px、透明度 10%，几乎不可见，但仍按间隔移动。
- **移动间隔**：可选 1 / 3 / 5 / 10 分钟（默认 3 分钟），到点后**瞬移**到屏幕上的随机位置，没有滑动过程。
- **悬浮点透明度**：10%–80%，越低越隐蔽。
- 关闭再打开开关，悬浮点会**立即回到屏幕左上角**。

> 若提示「还没授予悬浮窗权限」，点提示即可跳转授权；授权后回到应用会自动重新显示。

## 八、备份与恢复（建议定期做）

「设置 → 本地备份」：

1. **保存位置**：先选择一个文件夹，作为所有备份的存放地。
2. **手动备份**：生成并覆盖「胶囊伙伴-手动备份.json」。
3. **导入备份**：选择备份文件恢复，**会覆盖当前的待办、伙伴成长和提醒规则**，导入前建议先手动备份一次。
4. **快速备份**：点「今天」页顶部伙伴气泡即可，覆盖「胶囊伙伴-快速备份.json」。
5. **自动备份**：新建任务或新建提醒规则时自动保存，覆盖「胶囊伙伴-自动备份.json」。

三种备份各自固定一个文件，重复备份只覆盖上一次，不会越存越多；早期版本留下的「手动备份-日期-时间」文件会在下一次手动备份时自动清理。

备份文件是 JSON，保存在你自己选择的文件夹里，不经过网络。

## 九、数据与隐私

- 应用**没有 INTERNET 权限**，不会也无法上传任何数据。
- 节假日与农历均为本地离线计算。
- 卸载应用会清空本地数据，请在卸载前先做一次手动备份。

## 十、常见问题

**提醒不准时或收不到？**
依次检查：通知权限是否开启 → 精确闹钟是否允许 → 是否加入电池优化白名单 → 是否允许自启动 → 最后到「上岛通道」点一次「重新调度全部提醒」。

**上岛不可用？**
先确认通知权限正常；若设备不是 ColorOS 16+，或系统未开放实况通知能力，可能无法上岛，这不影响普通通知与提醒本身。

**悬浮点不见了？**
先确认「后台保持陪伴」仍是开启状态；再确认悬浮窗权限没有关闭；如果是「悬浮点隐藏」状态，它只有 1px，属于正常表现。

**备份失败？**
多半是保存位置失效（文件夹被删除或权限被回收）。重新在「保存位置」里选一次文件夹，再手动备份。

**换手机怎么迁移？**
旧手机做一次手动备份，把 JSON 文件传到新手机，安装后选择同一个文件夹，用「导入备份」恢复。

**导入后数据不对？**
导入是覆盖式的，会以备份文件为准。请确认选择的是想要的那份备份；如选错，可再用另一份备份导入一次。
